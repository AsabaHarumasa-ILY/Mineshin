# Minecraft x 原神 模组仓库(一号库)

#### 介绍
基于《原神》游戏的元素反应系统所开发的Minecraft模组仓库，在MC中添加了一个以《原神》游戏中的元素反应系统为蓝本的模组。

#### 现有功能
* 七种基础元素系统（水、火、雷、冰、风、草、岩）
* 基于原神规则的元素反应（蒸发、融化、超导、扩散、感电等）
* 右上角HUD元素显示
* 实体头顶元素名称显示
* 对应元素的粒子效果
* 对包含有原版魔咒的武器支持(例如火矢，引雷等)
* 持续时间管理和环境交互
* 轻量级GPU占用
* 根据地形和生物群系的不同，为生物添加了不同的元素
* 支持原神的各类伤害乘区计算(**未实现**)

#### 未来预期有的功能(基于其他模组联动使用)
* 原版生命值系统更改
* 全新角色GUI(包括圣遗物插槽)
* 新增血量/防御/防御/双暴等基于《原神》角色面板的角色GUI
